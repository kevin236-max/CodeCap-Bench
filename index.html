01 / The benchmark

Structured visuals. Rich dynamics.

CodeCap-Bench focuses on 2D content that can be represented programmatically: shapes, text, layouts, and explicit object trajectories. Fine-grained annotations capture both what appears and how it changes.

02 / Evaluation

Beyond “does it look similar?”

Generated code is rendered into a video and compared with the reference along three complementary dimensions. The pure-code setting requires visual content to be generated programmatically, without reusing reference imagery or external visual assets.

03 / Key findings

Rendering is only the beginning.

Producing a video does not guarantee faithful preservation of its information. Models differ substantially in visual fidelity, and temporal dynamics remain a consistent challenge.
